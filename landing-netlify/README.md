# PSi 4.0 PRO | Prontuário Inteligente & IA Clínica para Terapeutas

Landing page oficial de alta conversão do **PSi 4.0 PRO**, desenvolvida para psicólogos, psicanalistas e terapeutas com foco em conformidade ética (CFP 01/2009 e 004/2020), segurança de dados e alta performance no Vercel.

---

## 🚀 Estrutura dos Arquivos

- `index.html`: Página principal completa com design editorial, responsividade mobile, tags Open Graph para WhatsApp e ícones SVG.
- `favicon.ico`, `favicon.svg`, `favicon-32x32.png`: Ícones oficiais para abas do navegador (Chrome, Safari, iOS, Edge).
- `painel_clinico_referencia.png`, `teleconsulta_acolhimento.jpg`: Imagens e fotos de alta resolução da interface.

---

## 🛠️ Como Publicar no Vercel

1. Suba estes arquivos diretamente na raiz do seu repositório no GitHub.
2. O Vercel detecta automaticamente e publica a landing page em `https://psi40pro.vercel.app/`.
